# 다음 세션 프롬프트 남기기

루트의 `NEXT_SESSION_PROMPT.md`를 이번 세션까지의 최신 상태로 다시 쓴다. 다른 세션에서 이 파일 하나만 붙여 넣으면 바로 이어서 작업할 수 있어야 한다.

## 순서
1. 지금 `NEXT_SESSION_PROMPT.md`와 `CLAUDE.md`를 읽는다.
2. 사실 확인 (대화 기억만 믿지 말 것)
   - `git status --short`, `git log --oneline -5`로 커밋 안 된 변경을 확인한다.
   - 이번 세션에서 바뀐 스크립트(`Assets/01. Scripts/Rappel/`)를 읽고 동작과 인스펙터 값을 확인한다.
   - 씬 연결/값은 저장된 씬 파일 `Assets/00. Scene/00. TestScene.unity`에서 grep으로 확인한다. 파일 수정 시간도 확인해서 "몇 시 저장 기준"으로 적는다. 씬 파일은 읽기만 하고 수정하지 않는다.
3. 아래 형식으로 파일 전체를 다시 쓴다.
4. 사용자에게 무엇을 적었는지 짧게 알려 준다. 커밋은 하지 않는다 (사용자가 함).

## 형식 (섹션 순서 유지)
```
Rappel VR 프로젝트를 이어서 진행할게. 프로젝트 정보, 일정은 CLAUDE.md에 있으니 먼저 읽어 줘. 기획서(Assets/02. Docs/Rappel — 컨셉 기획서.pdf)도 읽어 줘.
단, CLAUDE.md는 <CLAUDE.md 마지막 갱신 시점> 기준이라 아래 내용이 더 최신이야.

## 작업 규칙
(기존 파일의 작업 규칙을 그대로 옮긴다. 이번 세션에서 사용자가 새로 정한 규칙만 추가한다.)

## <날짜(요일) 시각> 기준 진행 상황
### 끝난 것
### 스크립트 변경 (Assets/01. Scripts/Rappel/)
  - 스크립트별: 무엇을 하는지, 인스펙터 기본값, 바뀐 점
  - 씬 연결 (몇 시 저장 기준)
  - 실행 순서
### 알아둘 사실
  - 버그가 될 수 있는 점, 포기/결정한 것과 이유, CLAUDE.md에서 낡은 부분, 커밋 안 된 변경
## 다음 할 일 (<날짜>)
  - CLAUDE.md 일정 기준 남은 항목, 순서대로. 밀리면 CLAUDE.md "자를 순서"를 따른다
  - 그날 완료 기준 한 줄
```

## 지킬 것
- 한국어로 쓴다. 짧은 bullet 위주.
- 확인 못 한 것은 "확인 안 함"이라고 적는다. 추측으로 채우지 않는다.
- 새 기능이나 설계를 제안하지 않는다. 사용자가 정한 구조와 결정만 적는다.
- 일정은 CLAUDE.md의 마감/일정/자를 순서를 기준으로 한다.
